# Gate CI del hito v2.9

Este hito debe mantener en verde la compilación Android universal y todas las pruebas heredadas. Además, las suites nuevas deben comprobar el conjunto de multiselección y la clasificación exterior/interior de una cara plana anular.

La aprobación del gate no se interpreta como validación física prolongada ni como prueba de edición de subformas importadas.
